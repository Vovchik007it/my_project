 Виджет банковских операций:

Проект содержит функции для обработки списка банковских операций:
фильтрации по статусу и сортировки по дате.

 Установка:

Клонируйте репозиторий и перейдите в его директорию:

git clone <URL-вашего-репозитория>
cd <имя-репозитория>

Добавленны тест функции для файлов:
test_masks.py
test_widget.py
test_processing.py
